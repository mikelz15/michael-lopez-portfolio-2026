# Michael Lopez · Portfolio 2026

Professional portfolio site (static HTML/CSS/JS) built from the **Portfolio 2026 / tools pack** and resume.

## Local preview

```bash
cd ~/Desktop/Michael_Lopez_Portfolio_2026
# any static server, e.g.:
npx serve .
# or: python3 -m http.server 5173
```

Open http://localhost:3000 (or the port printed).

## Free deploy (Vercel)

```bash
cd ~/Desktop/Michael_Lopez_Portfolio_2026
npx vercel --yes
npx vercel --prod --yes
```

Or import the folder in [vercel.com/new](https://vercel.com/new) (Framework: Other / static).

Optional custom domain later: `portfolio.totalrewardsaccelerator.com` or a personal domain.
